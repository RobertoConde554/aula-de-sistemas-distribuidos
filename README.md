

Nesta aula foram utilizados os comandos **PING** e **NSLOOKUP** no CMD do Windows.

* **PING:** utilizado para testar a conexão com um domínio e verificar o tempo de resposta e possíveis perdas de pacotes.
* **NSLOOKUP:** utilizado para consultar o DNS e descobrir os endereços IP relacionados a um domínio.
* Foram realizados testes com `google.com` e `youtube.com`.
* O **DNS** transforma nomes de domínio em endereços IP.

Utilizamos o domínio em vez do IP porque é **mais fácil de memorizar e utilizar**.
